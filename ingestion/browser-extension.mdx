title: "Browser Extension"
description: "Clip any webpage, article, or web-based content directly into a SpecAI project knowledge base"
---

The **browser extension** (`apps/extension`) is SpecAI's most lightweight ingestion source. It lets you capture web content — a requirements doc on Notion, a decision thread in a GitHub issue, an article you're referencing — without leaving the browser.

## What you can clip

- Web pages and articles
- Online documents (Google Docs, Notion pages, Confluence pages viewed in browser)
- GitHub issues and pull request descriptions
- Any text-heavy web content

## How it works

<Steps>
  <Step title="Select content">
    Highlight text on any webpage, or clip the entire page.
  </Step>
  <Step title="Choose project">
    The extension popup lets you select which SpecAI project this clip belongs to.
  </Step>
  <Step title="Send to Core">
    The extension sends the clipped content (text \+ source URL \+ metadata) to the Core service's ingestion endpoint, authenticated with the user's JWT.
  </Step>
  <Step title="Process">
    Core routes the content through the standard ingestion pipeline — chunked, embedded, stored in pgvector. Status appears in the project dashboard.
  </Step>
</Steps>

## Authentication

The extension uses the user's active SpecAI session (JWT stored in extension storage after login) to authenticate ingestion requests. The user must be logged in to the SpecAI web app in the same browser profile.
