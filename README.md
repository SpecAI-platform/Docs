# SpecAI Docs
Documentation for **SpecAI** — built with [Mintlify](https://mintlify.com).
## Sections
| Section | Description |
|---|---|
| **Agents** | Chatbot, Insights, SRS, and Tester agents |
| **Ingestion** | File upload, GitHub, Jira/Confluence, email, browser extension |
| **Architecture** | Services, caching, security, and system overview |
| **Infrastructure** | Hosting, CI/CD, deployment, and branch protection |
| **Contributing** | Setup guide, env vars, roadmap, and troubleshooting |
## Local Development
```bash
npm i -g mint
mint dev
```
Preview at `http://localhost:3000`.
## Deploying
Push to `main` — changes deploy automatically via the [Mintlify GitHub app](https://dashboard.mintlify.com/settings/organization/github-app).
