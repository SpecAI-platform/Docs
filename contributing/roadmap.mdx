## What's complete

## In progress

<Warning>
  Items below are actively being worked on — coordinate before starting work in these areas.
</Warning>

- **Database schema design** — finalizing Postgres table structures for projects, documents, embeddings, RBAC, agent jobs
- **Caching layer wiring** — connecting Redis (Upstash) to all services for JWKS, RBAC, RAG, and job-status caching
- **Realtime layer wiring** — Supabase Realtime subscriptions in `apps/web` for live ingestion and agent job status
- **Agent logic build-out** — all six agents are scaffolded; real generation/retrieval logic is being built service by service
