This is the complete reference for every environment variable in the SpecAI monorepo. Two `.env` files are needed: one at the **repo root** and one in **`apps/web`**.

## Repo root `.env`

Copy from `.env.example` at the repo root:

```bash
cp .env.example .env
```

### Internal auth

| Variable | Example | Used by | Notes |
| --- | --- | --- | --- |
| `INTERNAL_API_KEY` | `any-strong-random-string` | All services | Shared secret for service-to-service calls. Set the same value in all services. |

### Supabase

| Variable | Where to find | Used by | Notes |
| --- | --- | --- | --- |
| `SUPABASE_URL` | Supabase project settings → API | All services | Public project URL |
| `SUPABASE_ANON_KEY` | Supabase project settings → API | apps/web, all services | Public — safe for browser |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase project settings → API | Backend services only | **Secret** — bypasses RLS, never expose to browser |
| `SUPABASE_DB_URL` | Supabase → Connect → Transaction Pooler | services that run migrations | Direct Postgres connection string |

### Upstash (Redis)

| Variable | Where to find | Used by |
| --- | --- | --- |
| `UPSTASH_REDIS_REST_URL` | Upstash dashboard → Redis instance | All services (caching) |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash dashboard → Redis instance | All services (caching) |

### Upstash (QStash)

## `apps/web/.env.local`

Next.js only loads env files from its own directory, so `apps/web` needs its own file:

```bash
cd apps/web
cp .env.example .env.local
```

Copy the relevant values from the root `.env`:

| Variable | Value |
| --- | --- |
| `INTERNAL_API_KEY` | Same as root `.env` |
| `NEXT_PUBLIC_SUPABASE_URL` | Same as `SUPABASE_URL` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Same as `SUPABASE_ANON_KEY` |
| `CORE_SERVICE_URL` | Same as root |
| `AUTH_SERVICE_URL` | Same as root |
| (other service URLs as needed) | Same as root |

<Warning>
  Never put `SUPABASE_SERVICE_ROLE_KEY` in `apps/web/.env.local` or any client-side env var. It must only exist in backend service environments.
</Warning>

## GitHub Actions secrets

Required secrets in the GitHub repository for CI/CD:

| Secret | Used for |
| --- | --- |
| `VERCEL_TOKEN` | Vercel CLI authentication |
| `VERCEL_ORG_ID` | Identifies the Vercel org |
| `VERCEL_PROJECT_ID` | Identifies the Vercel project |
| `RENDER_DEPLOY_HOOK_CORE` | Deploy hook URL for Core service on Render |
| `RENDER_DEPLOY_HOOK_AUTH` | Deploy hook URL for Auth service |
| `RENDER_DEPLOY_HOOK_MAIL` | Deploy hook URL for Mail service |
| `RENDER_DEPLOY_HOOK_JOBS` | Deploy hook URL for Jobs service |
| `RENDER_DEPLOY_HOOK_CONNECTORS` | Deploy hook URL for Connectors service |
