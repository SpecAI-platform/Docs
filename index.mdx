**SpecAI** is a multi-tenant SaaS platform that helps freelancers, engineers, and small teams capture scattered project context — emails, uploaded documents, browser-clipped content, and GitHub activity — into a **single searchable knowledge base per project**. AI agents then turn that knowledge base into useful outputs.

## The problem SpecAI solves

Small teams and solo builders lose project context constantly — decisions made in a Slack thread, a requirement mentioned in an email, a note taken during a call — none of it ends up anywhere searchable. Handoffs between teammates lose everything that wasn’t written down formally.

SpecAI **ingests that scattered context automatically**, stores it centrally per project, and lets AI agents work directly against it.

## How it works

<Steps>
  <Step title="Ingest">
    Content enters the system via a **browser clipper extension**, **direct file upload**, **inbound email parsing**, or **GitHub activity** (commits, PRs, issues).
  </Step>
  <Step title="Process">
    Ingested content is chunked, embedded, and stored in a vector database alongside relational project data — retrievable by meaning, not just keyword.
  </Step>
  <Step title="Knowledge base">
    Each project gets its own knowledge base — a combination of structured data (Postgres) and vector embeddings (pgvector) as a single source of truth.
  </Step>
  <Step title="AI agents act">
    Six specialized AI agents operate on the knowledge base to generate requirements documents, answer questions, surface risks, create JIRA tickets, publish Confluence pages, and generate test scenarios.
  </Step>
</Steps>

## Six AI agents

<CardGroup cols={2}>
  <Card title="SRS Document Agent" icon="file-lines" href="/agents/srs">
    Generates Software Requirements Specification documents using the MoSCoW method (Must/Should/Could/Won’t).
  </Card>

  <Card title="Chatbot Agent" icon="message-bot" href="/agents/chatbot">
    Real-time RAG chatbot that answers questions about the project, citing the source documents it used.
  </Card>

  <Card title="Insights Agent" icon="chart-mixed" href="/agents/insights">
    Analyzes the knowledge base to surface risks, gaps, and pivot-table-style project-state breakdowns.
  </Card>

  <Card title="JIRA Agent" icon="ticket" href="/agents/jira">
    Decides when a ticket should be created and files it directly into the connected JIRA project.
  </Card>

  <Card title="Confluence Agent" icon="book" href="/agents/confluence">
    Decides when documentation should be published and creates or updates Confluence pages.
  </Card>

  <Card title="Tester Agent" icon="flask" href="/agents/tester">
    Generates test cases and scenarios (conditions that must hold true) from ingested structured data.
  </Card>
</CardGroup>

## Target users

Freelancers, independent engineers, and small teams who need **lightweight project-memory and documentation automation** without a heavy compliance or enterprise tooling footprint.
